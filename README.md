# Introduction au C++ : Pokemon

Ce projet a pour but de prendre en main le langage C++ à travers une interface basée sur les jeux pokemon.

## Structure du projet :

```/inc ```
fichiers d'en-tête

```/src```
fichiers de classe et ```main.cpp```

```/media ```
fichiers externes utiles au projet (images, pokedex, ...)

## Compilation & Run : 

    $ cmake -S . -B build
    $ cmake --build build
    $ ./build/pokemon
