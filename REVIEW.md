Nicolas Polonowski

## Readme : ##

Le readme semble léger, seulement un titre et les indications pour compiler et lancer le programme.
Je pense qu’il faut au moins quelques lignes pour indiquer l’intérêt du dépôt et pour savoir de quoi il s'agit, ainsi qu’un détail de la structure du projet.

## Dépôt Git : ##

On remarque qu’on trouve les fichiers de compilation dans le dépôt, ce qui me semble être une erreur et alourdit le dépôt.

## Fichiers du code : ##

On trouve très peu de commentaires pour expliquer le fonctionnement et l’utilité des classes créées, on lit principalement des commentaires inutiles pour indiquer les constructeurs ou destructeurs des classes.

Je remarque cependant une pratique que je n’ai pas pensé à mettre dans mon code : l’utilisation d’une variable globale dans le fichier main.h pour indiquer le chemin relatif du fichier pokedex.csv.
